# Weekly AI Newsletter Generation

You are generating a weekly AI newsletter. Follow these steps precisely.

## Step 1: Load Configuration

Read the file `config.json` in the current working directory. It contains:
- `intent`: your editorial goal and audience description
- `output.sections`: the sections to include, in order
- `output.tone`: the writing style
- `sources`: list of URLs to fetch, with priority levels
- `filters`: topics to skip or boost

## Step 2: Fetch Sources

For each source in `config.json`, use WebFetch to retrieve the page. Process **high priority** sources first, then **medium**, then **low**. For each source:
- Extract post titles, dates, and brief descriptions published in the last 7 days
- Note any major announcements, releases, or research

If a source fails to load, skip it and continue.

Also run 2-3 WebSearch queries to catch anything the direct sources may have missed:
- "AI news this week [current date]"  
- "new LLM model release [current week]"
- "AI research paper [current week]"

## Step 3: Deduplicate & Filter

- Remove duplicate stories (same event covered by multiple sources — keep the most informative version)
- Apply `filters.skip_topics` and `filters.boost_topics` from config
- Only include items from the past 7 days
- Prioritize items from high-priority sources and boosted topics

## Step 4: Write the Newsletter

Use the `intent` from config to guide your editorial judgment. Write the newsletter with:

1. A header: `# AI Newsletter — Week of [date]`
2. A 2-sentence intro summarizing the week's overall theme
3. Each section from `output.sections`, in order
4. A footer: `---\n*Generated by Claude Code on [date]. Sources: [comma-separated source names used]*`

Follow the `tone` setting strictly. Be concise. Do not pad with filler.

## Step 5: Save Output

Write the newsletter to a file named `output/newsletter-YYYY-MM-DD.md` where the date is today's date.
Create the `output/` directory if it does not exist.

Also append a one-line entry to `output/index.md` in the format:
`- [Newsletter YYYY-MM-DD](newsletter-YYYY-MM-DD.md) — [one sentence summary of the week's theme]`

Report "Newsletter saved to output/newsletter-YYYY-MM-DD.md" when done.
